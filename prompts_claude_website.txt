Работаем с текущим проектом сайта.

Задача:
1. В корне проекта есть папка "фото".
2. Нужно взять фотографии из папки "фото" и встроить их в сайт по стилю и логике, похожей на сайт citymebel.online: на главной странице должны быть аккуратные визуальные блоки с фото реализованных работ / примеров мебели.
3. На первой странице нужно вывести не все фото, а только 5–7 лучших фотографий в виде красивого блока-превью.
4. Также нужно сделать отдельную страницу "Фотогалерея", куда вывести все фотографии из папки "фото".
5. На главной странице у блока с фото должна быть кнопка или ссылка "Смотреть все" / "Перейти в галерею", ведущая на страницу фотогалереи.

- Используй уже существующие стили проекта, а если нужно — аккуратно дополни их.
- Сделай современный, чистый, дорогой визуально блок.
- Адаптивность обязательна: desktop, tablet, mobile.
- Фото должны корректно масштабироваться, не растягиваться, выглядеть аккуратно.
- Желательно сделать hover-эффекты: легкое увеличение, затемнение, подпись или иконка просмотра.
- На главной странице фото должны быть оформлены как привлекательная витрина, как на мебельных сайтах.
- На странице "Фотогалерея" сделай полноценную сетку всех изображений.
- Если возможно, добавь открытие фото в lightbox / модальном окне при клике.
- Если проект на React / Next.js / Vue / чистом HTML/CSS/JS — определи стек сам и внеси изменения нативно под текущую архитектуру проекта.
- Не используй заглушки, работай именно с файлами из папки "фото".
- Если имена файлов нужно обработать программно — сделай это.
- Если фото много, на главной выведи только 5–7, а остальные только в галерее.
- Страница галереи должна быть отдельным маршрутом / отдельной страницей.

1. Сразу внеси изменения в код.
2. Покажи, какие файлы ты изменил.
3. Если создаешь новые файлы — покажи их полный код.
